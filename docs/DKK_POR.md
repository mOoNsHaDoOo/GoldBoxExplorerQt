# Death Knights of Krynn and Pool of Radiance (Amiga)

Formats taken from the C ports of the two executables (repositories
DeathKnightsRemakeC and PoolOfRadiance). Field names are generated by
`tools/gen_record_layouts.py` into `src/parse/record_layouts_gen.cpp`:

```
tools/gen_record_layouts.py DeathKnightsRemakeC/src PoolOfRadiance/src > src/parse/record_layouts_gen.cpp
```

| File | Source | Viewer |
| --- | --- | --- |
| `PIC1/PIC2/SPRIT1.DAA` (DKK) | `load_sequence`, `sequence_frame` (h049_pictures.c) | picture sequences: $5E-byte packed header, up to ten frames; SPRIT frames are stored whole (Champions of Krynn XORs them with the first frame) |
| `globals.daa` (DKK) | `load_globals` (h006_files.c), `dkk_unpack` (h032_unpack.c) | Huffman + run-length unpacked $7FEA-byte H004 image with the field names of h004_image.c |
| `CHRDATAn.gam`, `*.pch` (DKK) | `save_character` (h069_save_load.c), records.c | $E8-byte character |
| `.wiz` (DKK) | character.h | $DC-byte spell block: memorized, known, slots |
| `.jnk`, `.eff` (DKK) | records.c | $48-byte items, $0A-byte effects |
| `savgam?.pty` (DKK) | `save_game` (h069_save_load.c), state_blocks.c | resource group, states A/B/C, party position, game modes, wall sets, character files |
| `*.cha`, `.sav` of $120 bytes (PoR) | `save_char_to_disk` (mod16.c), include/game.h | character |
| `.itm`, `.spc` (PoR) | include/game.h | $41-byte items, 10-byte affects |
| `mes` (PoR crack notes) | - | text, ANSI sequences removed |

## Coverage

On the game disks (data files; AmigaOS executables excluded), files read by a
specific viewer, before and after:

| Game | Before | After | Left in hex |
| --- | --- | --- | --- |
| Death Knights of Krynn | 63 / 93 | 89 / 93 | `.info` lists, `Directoryinfo`, `system-configuration` |
| Pool of Radiance | 43 / 58 | 55 / 58 | `.info` list, `system-configuration` |

The same run (with the GLIB work of docs/AMIGA_GLIB.md) gives Curse of the
Azure Bonds 41/53, Secret of the Silver Blades 37/43, Pools of Darkness 49/57,
Dark Queen of Krynn 41/49 and Champions of Krynn 81/83, with no file that
regressed. What remains there: character saves (`.guy`, `.pty`, `.qsv`, `.pc`),
`*.FON` fonts, `spindisk`, and the AmigaOS system files.
